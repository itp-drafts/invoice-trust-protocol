# Invoice Trust Protocol (ITP)

This is the working area for the Invoice Trust Protocol Internet-Drafts.
They are individual drafts and have not been adopted by any IETF working group.

ITP describes how a business finds where another business receives
electronic invoices, delivers a signed invoice over HTTP, and lets any later
holder check who issued it, that it was not changed, and which tax
registrations exist for it. It carries existing invoice formats (UBL, CII,
national XML) and works next to Peppol and national clearance platforms.

## Discussion

Discussion takes place on the [DISPATCH mailing list](https://mailarchive.ietf.org/arch/browse/dispatch/)
(dispatch@ietf.org). Issues and pull requests in this repository are welcome too.

The author is looking for co-authors and for independent implementers.

## Command Line Usage

Formatted text and HTML versions of the drafts can be built using `make`.

```sh
$ make
```

Command line usage requires that you have the necessary software installed.  See
[the instructions](https://github.com/martinthomson/i-d-template/blob/main/doc/SETUP.md).
